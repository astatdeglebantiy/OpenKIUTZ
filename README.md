# OpenKIUTZ

OpenKIUTZ — це відкрита студентська платформа, база знань та автономний веб-движок для Фахового коледжу інформаційних технологій та землевпорядкування Національного авіаційного університету (КІУТЗ НАУ).

Движок оптимізований для розгортання на Raspberry Pi 5 і працює без сторонніх залежностей на чистому Python.

* **Офіційний сайт проєкту:** [https://kiutz.astatdeglebantiy.pp.ua](https://kiutz.astatdeglebantiy.pp.ua)
* **Статус платформи:** Працює цілодобово на базі Raspberry Pi 5 через Cloudflare Tunnel

---

## Основні можливості

* **Власний ООП Markdown-парсер**: модульна архітектура правил розбору (таблиці, списки завдань, цитати, заголовки, ізоляція сирого HTML/CSS/JS).
* **Серверні макроси Python (SSR)**: динамічна генерація даних під час рендерингу сторінок (`@schedule`, `@groups_catalog`, `@news_list` і т.д.).
* **Система розкладу занять**: автоматичний розрахунок тижнів за київським часом (`Europe/Kyiv`), розклад дзвінків, кабінети та прямі посилання для приєднання до Google Classroom/Meet.
* **Академічні доменні моделі**: структуроване представлення спеціальностей, груп, кураторів та старост через `groups.yaml`.
* **Швидкий пошук**: клієнтська фільтрація сторінок у реальному часі через випадаюче меню в шапці сайту.
* **Автономне розгортання**: незмінний (immutable) мультиплатформений Docker-образ на базі Alpine Linux (ARM64 / AMD64) з автоматичним деплоєм через GitHub Actions.
* **Відкритий вихідний код**: ліцензія MIT.

## Локальний запуск для розробки

Вимоги: Python 3.12 або новіше.

```bash
git clone https://github.com/astatdeglebantiy/OpenKIUTZ.git
cd OpenKIUTZ

# Запуск сервера
python main.py
```

Сайт буде доступний за адресою: `http://localhost:3000`.

---

## Розгортання через Docker

### 1. Збірка та запуск локально

```bash
docker compose up -d --build
```

### 2. Запуск на сервері (Raspberry Pi 5) через публічний образ

На сервері достатньо розмістити `docker-compose.yaml`:

```yaml
services:
  site:
    image: ghcr.io/astatdeglebantiy/openkiutz:latest
    container_name: openkiutz
    restart: unless-stopped
```

## Оформлення статей новин (`inwards/news/*.md`)

Кожен файл у папці `inwards/news/` повинен містити метадані у блоці `---`:

```markdown
---
title: Заголовок новини
date: 04.09.2026
description: Короткий опис новини для відображення у списку.
---

# Заголовок новини

Текст статті...
```
